Конструктор рецептов 107-1/у
Проект предназначен для подготовки рецептурных бланков формы № 107-1/у на основе Word-шаблона и автоматической подстановки данных из Python.

Шаблон содержит форму, утверждённую приказом Минздрава России от 24.11.2021 № 1094н. Перед практическим применением необходимо самостоятельно проверить актуальность нормативных требований, локальные правила медицинской организации и правильность сформированного рецепта.

Структура проекта
text
prescription_constructor/
├── templates/
│   └── prescription_107-1u_template.docx
├── README.md
└── .gitignore
Исходный шаблон находится в каталоге templates/. При генерации он используется только для чтения и не должен изменяться.

Готовые рецепты сохраняются на Рабочем столе текущего пользователя. Это позволяет быстро найти документ для проверки, печати или дальнейшей работы без перехода в каталог проекта.

Шаблон документа
Для автоматической подстановки используется синтаксис Jinja / docxtpl:

text
{{ variable_name }}
Каждый плейсхолдер должен быть набран в Word целиком и иметь единое символьное форматирование. Шрифт, размер, цвет и полужирное начертание плейсхолдера применяются к подставленному значению.

Не следует форматировать раздельно {{, имя переменной и }}.

Шаблон должен быть сохранён в формате .docx. Старый бинарный формат .doc не подходит для прямой обработки библиотеками docxtpl и python-docx.

Плейсхолдеры
Плейсхолдер	Назначение	Пример значения
{{ d }}	День даты выписки рецепта, две цифры	17
{{ m }}	Месяц даты выписки рецепта, две цифры	08
{{ y }}	Последние две цифры года	26
{{ patient_fio }}	Фамилия и инициалы пациента	Иванов И. И.
{{ patient_birthdate }}	Дата рождения пациента	01.01.1970
{{ doctor_fio }}	Фамилия и инициалы лечащего врача	Петров П. П.
{{ drug_1_form_name_dosage }}	Лекарственная форма, наименование и дозировка первого лекарственного препарата	таблетки, капецитабин 500 мг
{{ drug_1_signa }}	Способ применения первого лекарственного препарата (D.S. / signa)	По 2 таблетки внутрь 2 раза в сутки после еды.
В текущей версии шаблона автоматизирована первая лекарственная позиция. Две последующие позиции бланка оставлены пустыми. При необходимости их можно добавить по аналогии:

text
{{ drug_2_form_name_dosage }}
{{ drug_2_signa }}

{{ drug_3_form_name_dosage }}
{{ drug_3_signa }}
Генерация документа
Для заполнения шаблона предполагается использовать пакет docxtpl:

bash
pip install docxtpl
Пример контекста данных:

python
from datetime import date

issued = date.today()

context = {
    "d": issued.strftime("%d"),
    "m": issued.strftime("%m"),
    "y": issued.strftime("%y"),
    "patient_fio": "Иванов И. И.",
    "patient_birthdate": "01.01.1970",
    "doctor_fio": "Петров П. П.",
    "drug_1_form_name_dosage": "таблетки, капецитабин 500 мг",
    "drug_1_signa": "По 2 таблетки внутрь 2 раза в сутки после еды.",
}
Имя итогового файла должно однозначно идентифицировать документ, но не содержать лишних персональных данных. Например:

text
Рецепт_107-1у_2026-08-17_001.docx
Сохранение на Рабочий стол в Python:

python
from pathlib import Path

filename = "Рецепт_107-1у_2026-08-17_001.docx"
desktop = Path.home() / "Desktop"
output_path = desktop / filename
На компьютерах с нестандартным расположением Рабочего стола путь рекомендуется определять в настройках приложения или предоставить пользователю выбор каталога сохранения.

Правила репозитория
Версионируются: Word-шаблон, исходный код, README, конфигурация и тестовые данные без персональных данных.
Не версионируются: venv/, .venv/, __pycache__/, IDE-настройки, .env и любые реальные рецепты или документы с персональными данными.
Готовые рецепты не сохраняются в каталоге проекта и не добавляются в Git.
Для демонстрации и тестирования используются только обезличенные данные.

Рекомендуемое содержимое .gitignore:
text
venv/
.venv/

__pycache__/

.idea/
.vscode/
.env

Контроль перед печатью
Автоматическая генерация не заменяет врачебную проверку. Перед подписанием и выдачей рецепта необходимо проверить:
ФИО и дату рождения пациента.
Дату оформления и срок действия рецепта.
Лекарственную форму, наименование, дозировку и способ применения.
Соответствие количества назначений и заполненных строк бланка.
Требования к подписи, печати и иным обязательным реквизитам.
